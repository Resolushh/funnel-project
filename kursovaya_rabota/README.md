## Порядок сдачи

1. Создан отдельный публичный репозиторий `tz-11-turklub-tropa`; код сайта хранится там.
2. Сайт опубликован на Vercel. Этапы работы и проверки сохранены в истории проекта и документации.
3. README содержит ссылки, результаты, технологии, запуск и ограничения. В начале размещена таблица ссылок по образцу преподавателя.
4. Описание заполнено по разделам: задача, схема, сайт, GA4, UTM, заявки, Instagram, отчёты, результат и итог.
5. Схема подготовлена в PNG и SVG.
6. Финальные PDF и PPTX готовы: 12 слайдов в стиле проекта, заметки на 6:50. Фактическое время требует репетиции.
7. Ссылки и чек-лист заполнены в [бланке сдачи](kursovaya.md). Работы сдаются в `main`.
8. Защита проводится в назначенный преподавателем день.

## Защита

По образцу преподавателя доклад должен занимать до 7 минут. Для показа доступны сайт, QR, UTM-ссылки, форма и таблица заявок, обе ветки ManyChat, отчёты и исследования GA4. Расхождение заявок и событий объясняется по протоколу сверки. Финальная презентация готова; репетиция пока не проведена.

Использование ИИ раскрыто в бланке и журнале запросов проекта. Числа и результаты связаны с сохранёнными проверками; неподтверждённые этапы не отмечены выполненными.
